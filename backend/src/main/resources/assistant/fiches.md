# Fiches d'aide de l'assistant (mode sans IA)
#
# Chaque fiche commence par « ## » suivi de son titre, puis deux lignes :
#   pour : visiteur, apprenant, formateur, admin   (profils concernés)
#   mots : mots-clés qui déclenchent la fiche      (sans accents ni majuscules nécessaires)
# puis le texte de la réponse (listes, **gras** et liens [texte](/chemin) acceptés).
# L'assistant choisit la fiche la plus proche de la question, en privilégiant celles du profil connecté.

## Créer un compte
pour : visiteur
mots : creer compte inscription inscrire nouveau commencer rejoindre enregistrer
Rendez-vous sur la page [Inscription](/inscription) :
1. Choisissez votre profil : jeune du CDEJ de Kpévé, jeune d'un autre CDEJ ou particulier.
2. Renseignez vos nom, prénom, date de naissance, numéro de téléphone (l'e-mail est facultatif) et un mot de passe d'au moins 8 caractères.
3. Validez : votre espace apprenant s'ouvre aussitôt.

C'est gratuit et rapide. Vous pourrez ensuite choisir une formation dans le [catalogue](/formations).

## Se connecter
pour : visiteur
mots : connecter connexion identifiant login acceder espace entrer
Ouvrez la page [Connexion](/connexion) et saisissez votre numéro de téléphone (ou votre e-mail) et votre mot de passe. Mot de passe oublié ? Utilisez le lien **Mot de passe oublié** sous le formulaire.

## En ligne ou en salle
pour : visiteur
mots : ligne salle difference distance presentiel modalite domicile maison
Chaque formation se suit de deux façons :
- **En ligne** : les modules se débloquent au fur et à mesure, vous avancez à votre rythme sur ordinateur ou téléphone. L'examen final s'ouvre quand tous les modules sont terminés, et vous pouvez le repasser jusqu'à la réussite.
- **En salle** : le formateur donne le cours à l'Académie. L'examen final a lieu pendant la session qu'il programme, en une seule tentative.

Les jeunes du CDEJ de Kpévé suivent en principe en salle, les autres apprenants en ligne ; le formateur peut adapter la modalité.

## Obtenir un certificat
pour : visiteur
mots : obtenir certificat attestation diplome certification avoir recevoir
Deux documents peuvent être délivrés :
- **Attestation de suivi** : automatiquement, quand toutes les leçons de la formation sont terminées.
- **Certificat de compétence** : quand vous réussissez l'examen final (corrigé automatiquement).

Ils se téléchargent en PDF depuis votre espace et portent un QR code qui permet à un employeur de les [vérifier](/verifier). Pour commencer, [créez votre compte](/inscription) puis choisissez une [formation](/formations).

## Devenir formateur
pour : visiteur, apprenant
mots : devenir formateur enseigner professeur former donner cours animer
Les comptes formateurs sont créés par l'Académie. Écrivez-nous depuis la [page Contact](/contact) en choisissant le sujet **Devenir formateur** : après un échange, l'administration crée votre compte et vous communique vos identifiants.

## Choisir une formation
pour : visiteur, apprenant
mots : choisir formation catalogue cours trouver chercher domaine liste programme quelle conseiller
Le [catalogue](/formations) présente toutes les formations, avec des filtres par domaine, niveau, type de certification et durée. Chaque page de formation détaille le programme, le formateur, l'examen final et la certification. Pour s'inscrire : bouton **S'inscrire gratuitement** (accès immédiat) ou **Demander l'inscription** (validée par l'Académie).

## Passer l'examen final
pour : apprenant
mots : passer examen final commencer evaluation test epreuve quand ouvrir
Vos examens sont dans [Mes examens](/apprenant/examens) :
- **Formation en ligne** : l'examen s'ouvre dès que tous les modules sont terminés. Vous pouvez le repasser jusqu'à la réussite.
- **Formation en salle** : il a lieu pendant la session programmée par votre formateur (date et heure affichées dans **Mes examens**), en une seule tentative.

Pendant l'examen, restez sur la page : les changements d'onglet sont signalés au formateur. Vos réponses sont enregistrées à chaque clic.

## Résultat et nouvelle tentative
pour : apprenant
mots : resultat note echoue rate echec reussi repasser tentative recommencer score admis
L'examen est corrigé automatiquement : votre note s'affiche dès la fin, et vous la retrouvez dans [Mes examens](/apprenant/examens).
- **En ligne** : si vous n'avez pas atteint la note minimale, révisez les modules puis cliquez sur **Reprendre l'examen** : les tentatives sont illimitées.
- **En salle** : une seule tentative est prévue ; pour une nouvelle chance, parlez-en à votre formateur.

## Télécharger mon certificat
pour : apprenant
mots : telecharger certificat attestation pdf imprimer trouver ou voir mon
Ouvrez [Mes certificats](/apprenant/certificats), puis **Voir / télécharger** sur le document voulu : vous pouvez l'enregistrer en PDF ou l'imprimer. Un certificat marqué **en cours de validation** sera disponible dès que l'Académie l'aura vérifié ; vous recevrez une notification.

## Inscription en attente
pour : apprenant
mots : inscription attente demande validation acceptee refusee bloquee pas acces
Certaines formations demandent une validation : l'administration de l'Académie examine votre demande, puis vous recevez une notification dans [Notifications](/apprenant/notifications). Dès qu'elle est acceptée, la formation apparaît dans [Mes formations](/apprenant/formations). Si l'attente vous semble longue, [contactez l'Académie](/contact).

## Ma modalité (en ligne ou en salle)
pour : apprenant
mots : salle ligne modalite suis je mode presentiel distance changer
Votre modalité est indiquée sur chaque formation dans [Mes formations](/apprenant/formations) et dans [Mes examens](/apprenant/examens). Elle dépend de votre profil (jeunes du CDEJ de Kpévé en salle, autres apprenants en ligne) et votre formateur peut la changer : adressez-vous à lui si elle ne vous convient pas.

## Reprendre une formation
pour : apprenant
mots : reprendre continuer formation lecon module progression avancer suivre cours
Ouvrez [Mes formations](/apprenant/formations) et cliquez sur la formation : vous reprenez là où vous vous êtes arrêté, votre progression étant enregistrée automatiquement. Chaque module se termine par un **quiz d'entraînement**, corrigé tout de suite et non certifiant.

## Modifier mon profil ou mon mot de passe
pour : apprenant, formateur, admin
mots : modifier profil mot passe changer photo telephone email informations compte
Ouvrez **Mon profil** dans votre espace : vous y modifiez vos informations, et dans le bloc mot de passe vous saisissez l'actuel puis le nouveau avant de cliquer sur **Modifier le mot de passe**.

## Créer et publier une formation
pour : formateur
mots : creer publier formation nouvelle cours mettre ligne catalogue rendre visible
Dans [Mes formations](/formateur/formations), cliquez sur **Nouvelle formation**, puis suivez les onglets :
1. **Informations** : titre, résumé, description, domaine, niveau, durée, certification délivrée et mode d'inscription (libre ou soumise à validation).
2. **Cours en ligne** : modules et leçons (vidéo, texte, fichiers).
3. **Cours en salle** : support PDF et sessions d'examen en salle.
4. **Examen final** : paramètres et questions.
5. **Publication** : quand les vérifications sont au vert, cliquez sur **Publier la formation**. Elle apparaît aussitôt dans le catalogue.

## Ajouter des modules et des leçons
pour : formateur
mots : ajouter module lecon contenu video texte fichier pdf support cours ligne
Ouvrez la formation depuis [Mes formations](/formateur/formations), onglet **2. Cours en ligne** : créez un module, puis ajoutez-y des leçons (texte, lien de vidéo, fichier joint). Les flèches permettent de réordonner modules et leçons. Pensez à cliquer sur **Enregistrer le contenu**. Pour les cours en salle, déposez le support PDF dans l'onglet **3. Cours en salle**.

## Importer des questions
pour : formateur
mots : importer questions document word pdf fichier import qcm charger
Dans la [Banque de questions](/formateur/questions), choisissez la formation puis cliquez sur **Importer un document** (Word ou PDF). Indiquez si les questions vont à l'examen final ou au quiz d'un module, vérifiez l'aperçu, puis confirmez. Astuce : mettez la bonne réponse en gras, ou ajoutez « Réponse : b » sous la question.

## Créer une question
pour : formateur
mots : creer question nouvelle banque qcm vrai faux reponse courte bonne reponse ajouter quiz
Dans la [Banque de questions](/formateur/questions), choisissez la formation, puis l'onglet voulu (**Examen final** ou un module) et cliquez sur **Nouvelle question**. Choisissez le type (QCM à réponse unique ou multiple, vrai/faux, réponse courte), saisissez l'énoncé et cochez la ou les bonnes réponses. La correction est automatique.

## Configurer l'examen final
pour : formateur
mots : configurer parametres examen final note minimale duree questions candidat tirage aleatoire correction
Ouvrez la formation, onglet **4. Examen final** : réglez la durée, le nombre de questions par candidat, la note minimale (sur 100), le tirage aléatoire, l'affichage de la correction et, si besoin, la validation du certificat par l'administration. Cliquez ensuite sur **Enregistrer l'examen**.

## Programmer une session d'examen en salle
pour : formateur
mots : programmer session examen salle date heure jour planifier convoquer
Ouvrez la formation, onglet **3. Cours en salle**, section des sessions d'examen : indiquez le **Jour de l'examen**, l'heure de début et de fin, puis cliquez sur **Programmer la session**. Vos apprenants en salle voient la date dans leur page **Mes examens** et passent l'examen sur les postes de l'Académie, en une seule tentative.

## Suivre mes apprenants
pour : formateur
mots : suivre apprenants eleves progression notes resultats tentatives liste exporter excel csv
Ouvrez [Mes apprenants](/formateur/apprenants) : pour chacun, vous voyez la formation, la modalité, la progression, la meilleure note, le nombre de tentatives et les alertes. Filtrez par formation et utilisez **Exporter (Excel / CSV)** pour garder un tableau. Votre [tableau de bord](/formateur) résume aussi les derniers résultats d'examen.

## Changer la modalité d'un apprenant
pour : formateur
mots : changer modalite apprenant salle ligne passer basculer mode
Dans [Mes apprenants](/formateur/apprenants), utilisez la liste **Modalité** sur la ligne de l'apprenant pour choisir **En salle** ou **En ligne**. Le changement s'applique aussitôt à ses modules et à son examen final.

## Alertes anti-fraude
pour : formateur
mots : fraude triche alerte onglet changement suspect surveillance
Pendant un examen, chaque changement d'onglet ou d'application est enregistré. Les alertes apparaissent sur votre [tableau de bord](/formateur) (**Alertes anti-fraude**) et dans la colonne **Alertes** de [Mes apprenants](/formateur/apprenants).

## Créer un compte formateur
pour : admin
mots : creer compte formateur ajouter utilisateur nouveau identifiants
Dans [Utilisateurs](/admin/utilisateurs), onglet des formateurs, cliquez sur **Créer un compte formateur** : renseignez nom, téléphone et e-mail. Un mot de passe provisoire est affiché (et envoyé par SMS ou e-mail si l'envoi est activé) ; la personne le change ensuite dans **Mon profil**. **Import Excel** permet de créer plusieurs comptes à la fois.

## Valider une inscription
pour : admin
mots : valider inscription demande attente accepter refuser apprenant validation
Ouvrez [Validations](/admin/validations), onglet des inscriptions : acceptez ou refusez chaque demande. L'apprenant est prévenu par une notification. Le même écran présente les certificats en attente de validation.

## Mot de passe d'un utilisateur
pour : admin
mots : reinitialiser mot passe utilisateur provisoire oublie debloquer
Dans [Utilisateurs](/admin/utilisateurs), cliquez sur l'icône de clé de la ligne concernée : un mot de passe provisoire est créé et affiché, à communiquer à la personne (il lui est aussi envoyé si l'envoi par SMS ou e-mail est activé).

## Gérer les certificats
pour : admin
mots : certificat revoquer annuler valider modele recherche delivre signataire
Dans [Certificats](/admin/certificats), recherchez un document pour le consulter ou le **révoquer** (avec un motif) : il apparaîtra alors comme révoqué sur la page de vérification. Le second onglet permet de choisir le modèle de certificat et le signataire. Les certificats à valider sont dans [Validations](/admin/validations).

## Modifier le site vitrine
pour : admin
mots : modifier site vitrine faq actualite partenaire texte accueil coordonnees telephone page
Ouvrez [Site vitrine](/admin/site) : onglets **Actualités**, **Partenaires**, **FAQ**, textes et coordonnées (titre de l'accueil, mission, chiffres clés, téléphone, adresse…) et messages reçus par le formulaire de contact. Les changements sont visibles aussitôt, y compris par l'assistant.

mots : formation categorie domaine gerer archiver modifier toutes
[Formations & catégories](/admin/formations) liste toutes les formations de l'Académie (vous pouvez les ouvrir et les modifier) et permet de créer ou modifier les domaines du catalogue.

## Statistiques
pour : admin
mots : statistiques rapport chiffres export activite bilan
[Statistiques & rapports](/admin/statistiques) présente l'activité de l'Académie (inscriptions, réussite, certificats) et permet d'exporter les rapports.
